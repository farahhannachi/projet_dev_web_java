📱 QR CODE QUICKSTART - CuraVita

🎯 3 ÉTAPES SIMPLES

Étape 1️⃣ : Compiler
─────────────────
mvn clean install
Maven téléchargera les dépendances ZXing automatiquement.

Étape 2️⃣ : Intégrer dans votre contrôleur
──────────────────────────────────────────
import org.example.service.QRService;

QRService qrService = QRService.getInstance();
String filePath = qrService.generateServiceQRCodeWithInfo(
    service.getId(),
    service.getNom(),
    service.getType(),
    service.getSpecialite()
);

Étape 3️⃣ : Afficher dans JavaFX
────────────────────────────────
@FXML private ImageView qrCodeView;

Image qrImage = qrService.loadQRCodeImage(filePath);
qrCodeView.setImage(qrImage);

💻 AFFICHAGE DANS FXML
────────────────────────
<ImageView fx:id="qrCodeView"
           fitWidth="300"
           fitHeight="300"
           preserveRatio="true"/>

🎨 4 CAS D'USAGE
───���────────────

1️⃣ QR Simple (ID seulement)
   qrService.generateServiceQRCode(123, "Service#123");

2️⃣ QR Structuré (Infos du service)
   qrService.generateServiceQRCodeWithInfo(
       id, nom, type, specialite
   );

3️⃣ QR avec Lien URL
   qrService.generateServiceQRCodeWithLink(123, "http://localhost:8080");

4️⃣ QR en Mémoire (sans fichier)
   byte[] qrBytes = qrService.generateQRCodeBytes(123, "data");

🚀 EXEMPLE COMPLET D'INTÉGRATION
──────────────────────────────────

// Dans ServiceService.java - ajouter après insertion en BD
public boolean add(Service service) {
    // ... code CRUD existant ...

    // ✨ NOUVEAU: Générer QR code automatiquement
    if (service.getId() > 0) {
        QRService qrService = QRService.getInstance();
        qrService.generateServiceQRCodeWithInfo(
            service.getId(),
            service.getNom(),
            service.getType(),
            service.getSpecialite()
        );
    }
    return true;
}

📞 SUPPORT RAPIDE
──────────────────
❓ Où sont les QR codes?
→ Dossier: qr_codes/service_{id}.png

❓ Erreur: "Cannot find package com.google.zxing"?
→ Exécuter: mvn clean install

❓ ImageView n'affiche rien?
→ Vérifier: qrService.loadQRCodeImage() retourne non-null

❓ Puis-je modifier la taille?
→ Oui: Changer QR_CODE_SIZE dans QRService.java

👁️ VÉRIFICATION
────────────────
Après la première génération, vérifiez:
✓ Dossier qr_codes/ créé
✓ Fichiers service_*.png présents
✓ Images PNG valides (ouvrir avec image viewer)
✓ QRCodeView affiche l'image

💡 BONNES PRATIQUES
