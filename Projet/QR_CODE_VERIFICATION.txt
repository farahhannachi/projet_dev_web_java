ÉTAPE 5: Tester la génération
──────────────────────────────

Créer un petit programme de test:

```
public class TestQRGeneration {
    public static void main(String[] args) {
        QRService qr = QRService.getInstance();

        // Test 1: Génération simple
        String path1 = qr.generateServiceQRCode(1, "Test#1");
        System.out.println("Test 1 - Fichier créé: " + (path1 != null));

        // Test 2: Avec infos
        String path2 = qr.generateServiceQRCodeWithInfo(
            2, "Dr. Test", "Médecin", "Cardiologie"
        );
        System.out.println("Test 2 - Fichier créé: " + (path2 != null));

        // Test 3: Chargement image
        if (path2 != null) {
            Image img = qr.loadQRCodeImage(path2);
            System.out.println("Test 3 - Image chargée: " + (img != null));
        }
    }
}
```

  ✓ Test 1 - Fichier créé: true
  ✓ Test 2 - Fichier créé: true

ÉTAPE 7: Intégrer dans votre application
─────────────────────────────────────────

Dans votre contrôleur:

  ☐ Ajouter: @FXML private ImageView qrCodeView;
  ☐ Importer: import org.example.service.QRService;
  ☐ Ajouter la méthode:

    private void displayQRCode(Service service) {
        QRService qr = QRService.getInstance();
        String path = qr.generateServiceQRCodeWithInfo(
            service.getId(), service.getNom(),
            service.getType(), service.getSpecialite()
        );
        if (path != null) {
            Image img = qr.loadQRCodeImage(path);
            qrCodeView.setImage(img);
        }
    }

  ☐ Ajouter dans votre FXML:

    <ImageView fx:id="qrCodeView"
               fitWidth="300"
               fitHeight="300"
               preserveRatio="true"/>

❌ RÉSOLUTION DES PROBLÈMES
═════════════════════════════════════════════════════════════════════════════════════

Problème: Erreur "Cannot find package com.google.zxing"
─────────────────────────────────────────────────────────
Solution:
  1. Exécuter: mvn clean
  2. Exécuter: mvn install
  3. Attendre le téléchargement des dépendances (1-2 min)
  4. Vérifier pom.xml

Problème: QRService no found in project
─────────────────────────────────────────
Solution:
  1. Vérifier que QRService.java existe dans:
     src/main/java/org/example/service/
  2. Recharger le projet dans l'IDE
  3. mvn clean install

Problème: Image n'apparaît pas dans ImageView
───────────────────────────────────────────────
Solution:
  1. Vérifier que filePath n'est pas null
  2. Vérifier le fichier PNG existe dans qr_codes/
  3. Vérifier que ImageView a fitWidth/fitHeight
  4. Afficher les logs: System.out.println()

Problème: Dossier qr_codes/ n'existe pas
──────────────────────────────────────────
Solution:
  1. Vérifier les permissions d'écriture du projet
  2. Exécuter generateServiceQRCode() au moins une fois
  3. Dossier sera créé automatiquement
