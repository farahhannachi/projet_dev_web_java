ERREUR RENCONTRÉE:
  java.lang.NullPointerException: Cannot invoke "javafx.scene.layout.BorderPane.setCenter(javafx.scene.Node)"
  because "this.mainPane" is null

CAUSE:
  Le BorderPane dans Dashboard.fxml n'avait pas fx:id="mainPane"
  → Quand on cliquait sur "Dépôts", le code essayait d'utiliser mainPane
  → Mais mainPane était null (pas initialisé)

SOLUTION APPLIQUÉE:
  Ajouter fx:id="mainPane" au BorderPane dans Dashboard.fxml

AVANT ❌:
  <BorderPane xmlns="..." fx:controller="DashboardController" ...>

APRÈS ✅:
  <BorderPane xmlns="..." fx:id="mainPane" fx:controller="DashboardController" ...>
