## 🎓 Glossaire

```
Backend       = Partie serveur (Java/MySQL)
Frontend      = Partie client (JavaFX/FXML)
FXML          = Format XML pour interface JavaFX
Controller    = Classe gérant la logique UI
Service       = Classe gérant la logique métier
Model         = Classes représentant les données
MVC           = Modèle-Vue-Contrôleur
CRUD          = Create-Read-Update-Delete
Role-Based    = Basé sur les rôles utilisateur
```
