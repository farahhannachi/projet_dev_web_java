🚀 UTILISATION IMMÉDIATE
═════════════════════════════════════════════════════════════════

1. Compiler:
   mvn clean install

2. Générer QR pour un service:
   QRService qrService = QRService.getInstance();
   String filePath = qrService.generateServiceQRCodeWithInfo(
       service.getId(),
       service.getNom(),
       service.getType(),
       service.getSpecialite()
   );

3. Afficher dans JavaFX:
   Image qrImage = qrService.loadQRCodeImage(filePath);
   imageView.setImage(qrImage);

🔧 CONFIGURATION AVANCÉE
═════════════════════════════════════════════════════════════════

Taille du QR code:
   QRService.java, ligne 23:
   private static final int QR_CODE_SIZE = 300;
   Changez à votre guise (300, 256, 512, etc.)

Dossier de destination:
   QRService.java, ligne 22:
   private static final String QR_CODE_FOLDER = "qr_codes";
   Changez le chemin selon votre besoin

Format des données:
   Tous les formats sont supportés:
   - Simple: "Service#123"
   - Structuré: "id:123|nom:Dr. X|..."
   - URL: "http://localhost:8080/service/123"

⚠️ DÉPANNAGE
═════════════════════════════════════════════════════════════════

❓ Erreur: "Cannot find package com.google.zxing"
   → Exécuter: mvn clean install
   → Attendre le téléchargement des dépendances

❓ QR code n'apparaît pas
   → Vérifier le fichier PNG dans qr_codes/
   → Vérifier que loadQRCodeImage() ne retourne pas null

❓ Dossier qr_codes/ n'existe pas
   → Sera créé automatiquement à la première génération
   → Vérifier les permissions d'écriture

❓ Une seule instance du service?
   → Oui, utiliser: QRService.getInstance()
   (Singleton pattern)
