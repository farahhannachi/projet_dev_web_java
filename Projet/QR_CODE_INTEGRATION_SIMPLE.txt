## 🚀 UTILISATION SIMPLE

### **Génération automatique** (déjà configurée)
Chaque fois que vous ajoutez un service via `ServiceService.add()` :
```java
Service service = new Service(...);
serviceService.add(service); // ← Génère automatiquement le QR code
```

### **Affichage dans JavaFX**
```java
@FXML private ImageView qrCodeView;

public void showQRCode(Service service) {
    QRService qr = QRService.getInstance();
    String path = qr.generateServiceQRCodeWithInfo(
        service.getId(), service.getNom(),
        service.getType(), service.getSpecialite()
    );
    Image img = qr.loadQRCodeImage(path);
    qrCodeView.setImage(img);
}
```

## 📁 FICHIERS GÉNÉRÉS

- **QR codes PNG** : `qr_codes/service_{id}.png`
- **Format** : 300x300 pixels, scannable
- **Contenu** : `id:123|nom:Dr. X|type:Médecin|specialite:Cardio`

---

## 🔧 3 FORMATS DISPONIBLES

### Format 1: Structuré (par défaut)
```java
qrService.generateServiceQRCodeWithInfo(id, nom, type, specialite);
// → "id:123|nom:Dr. Mohamed|type:Médecin|specialite:Cardiologie"
```

### Format 2: URL
```java
qrService.generateServiceQRCodeWithLink(id, "http://localhost:8080");
// → "http://localhost:8080/service/123"
```

### Format 3: Simple
```java
qrService.generateServiceQRCode(id, "Service#123");
// → "Service#123"
```

## 📱 AFFICHAGE DANS JAVAFX

### Dans le contrôleur:
```java
@FXML private ImageView qrCodeView;

public void displayQR(Service service) {
    QRService qr = QRService.getInstance();
    String path = qr.generateServiceQRCodeWithInfo(
        service.getId(), service.getNom(),
        service.getType(), service.getSpecialite()
    );
    if (path != null) {
        Image img = qr.loadQRCodeImage(path);
        qrCodeView.setImage(img);
    }
}
```

### Dans le FXML:
```xml
<ImageView fx:id="qrCodeView"
           fitWidth="300"
           fitHeight="300"
           preserveRatio="true"/>
```
