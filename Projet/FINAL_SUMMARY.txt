## 💡 CONCEPT CLÉS

**Pattern Singleton**: Une seule instance de DepotService partage les données entre tous les contrôleurs.

```
Dashboard → getInstance() ──┐
                             ├─→ MÊME INSTANCE
DepotController → getInstance() ──┘

Résultat: Données synchronisées ✅
```
