       QRService qrService = QRService.getInstance();

       String filePath = qrService.generateServiceQRCodeWithInfo(
           service.getId(),
           service.getNom(),
           service.getType(),
           service.getSpecialite()
       );

       if (filePath != null) {
           Image qrImage = qrService.loadQRCodeImage(filePath);
           if (qrImage != null) {
               qrCodeImageView.setImage(qrImage);
               System.out.println("✅ QR code affiché pour: " + service.getNom());
           }
       }
   }

📋 RÉSUMÉ DU CODE MINIMAL
════════════════════════════════════════════════════════���════════════════════════════

Tout ce dont vous avez besoin:

```java
// Import
import org.example.service.QRService;

// UI Element
@FXML private ImageView qrCodeView;

// Afficher QR d'un service
private void showQRCode(Service service) {
    QRService qr = QRService.getInstance();
    String path = qr.generateServiceQRCodeWithInfo(
        service.getId(), service.getNom(),
        service.getType(), service.getSpecialite()
    );
    if (path != null) {
        Image img = qr.loadQRCodeImage(path);
        qrCodeView.setImage(img);
    }
}
```

C'est 12 lignes! C'est tout!
