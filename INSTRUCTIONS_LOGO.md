# Instructions pour ajouter votre logo

## Étape 1: Sauvegarder votre logo
1. Faites un clic droit sur l'image du logo que vous avez fournie
2. Sélectionnez "Enregistrer l'image sous..."
3. Sauvegardez-la dans: `curavita-pharmacy/public/images/logo-original.png`

## Étape 2: Le site utilisera automatiquement votre logo
Une fois le fichier sauvegardé, le logo apparaîtra automatiquement dans:
- La navigation du frontoffice (http://127.0.0.1:8000/)
- La navigation du backoffice (http://127.0.0.1:8000/admin)

## Note
Le logo sera affiché avec:
- Hauteur de 80px dans le frontoffice
- Hauteur de 75px dans le backoffice
- Fond transparent ou blanc circulaire comme dans votre image originale
