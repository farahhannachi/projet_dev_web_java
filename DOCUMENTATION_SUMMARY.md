## 💡 Points Clés

### Architecture
```
Interface (FXML)
    ↓ (événement)
Contrôleur (handleAddClient)
    ↓ (valide + appelle)
Service (addUser)
    ↓ (requête SQL)
Base de Données (INSERT)
    ↓ (succès/erreur)
Interface mise à jour
```

### Validation
```
Niveau 1: Interface (hints, minLength)
    ↓
Niveau 2: Contrôleur (validateForm)
    ↓
Niveau 3: Service (emailExists, regex)
    ↓
Niveau 4: BD (UNIQUE constraint)
```

### Sécurité
```
Password: "password123"
    ↓
BCrypt.hashpw(password, BCrypt.gensalt())
    ↓
Résultat: "$2a$10$YX7o0rHWL2..."
    ↓
Sauvegardé en BD (jamais plaintext)
```
